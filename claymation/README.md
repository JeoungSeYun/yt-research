# 떡이의 새싹 (Sprout) — 15초 클레이 애니메이션

![포스터](poster.jpg)

▶ 영상: [`sprout.mp4`](sprout.mp4) (1920×1080, 24fps, 15초, 사운드 포함)

## 줄거리

1. 말랑한 떡 캐릭터 **떡이**가 물뿌리개를 들고 깡총깡총 화분 앞으로 온다.
2. 영차, 물뿌리개를 번쩍 들어 화분에 물을 준다. 흙이 촉촉하게 젖는다.
3. 화분을 빤히 들여다보며 기다리지만… 아무 일도 없다. 고개를 갸웃. **?**
4. 한숨을 푹 쉬고 시무룩하게 돌아서 터덜터덜 걸어간다. *(빠-바-바-밤…)*
5. 그 순간, 등 뒤에서 새싹이 쑥쑥 자라더니 **뽕!** 하고 꽃이 핀다.
6. 깜짝 놀라 돌아본 떡이 **!** — 만세 점프!
7. 꽃과 서로 꾸벅 인사를 나누자, 떡이 머리 위 새싹에도 작은 꽃이 핀다.
8. **새싹** — 하트가 몽글몽글, 끝.

기다릴 땐 안 오다가 포기하고 돌아선 순간 쑥 자라는 — 말 그대로 *떡*이의 새싹이 떡상하는 이야기.

## 만든 방법

외부 모델·텍스처·음원 없이 **Blender 파이썬 스크립트(`sprout.py`) 하나**로 세트, 캐릭터, 재질, 애니메이션,
조명, 카메라를 전부 만들고, 음악과 효과음은 **`sound.py`에서 numpy/scipy로 직접 합성**했다.

- **스톱모션 방식**: 12fps로 한 장씩 포즈를 잡아 '촬영'(키프레임 보간 없음)하고, 24fps 영상에서 한 장을
  두 번씩 보여준다(on twos). 프레임마다 손으로 옮긴 듯한 미세한 흔들림, 점토 결이 살짝 바뀌는 '보일링',
  조명의 미세한 깜빡임을 넣었다.
- **점토 재질**: 보로노이 동심원으로 만든 지문 자국, 덩어리 요철, 잔결, 약한 표면하산란(SSS).
  캐릭터 표정은 실제 클레이 애니처럼 **입 모양 교체(replacement)** 방식.
- **스쿼시 & 스트레치**: 점프·착지마다 몸이 눌렸다 늘어나고, 물뿌리개를 들 때는 팔이 쭉 늘어난다.
- **미니어처 느낌**: 아주 얕은 피사계 심도(f/0.8), 종이에 칠한 하늘 배경, 점토로 빚은 구름과 해.
- **사운드**: 우쿨렐레(카플러스-스트롱 현)·마림바·글로켄슈필 음악, 물방울·뽕·슬픈 트롬본·슬라이드 휘슬 등
  효과음. 애니메이션에서 내보낸 타이밍(`--cues`)에 맞춰 자동으로 배치된다.

## 파일

| 파일 | 내용 |
|---|---|
| `sprout.mp4` | 완성 영상 |
| `poster.jpg` | 엔딩 장면 스틸 |
| `sprout.py` | Blender 장면·애니메이션 생성 + 렌더 |
| `sound.py` | 음악·효과음 합성 → WAV |
| `make_video.sh` | 렌더 → 사운드 → 인코딩 전체 파이프라인 |

## 다시 만들기

```bash
pip install bpy==4.5.4 scipy          # Blender 4.5 LTS 파이썬 모듈
sudo apt install ffmpeg fonts-nanum   # 인코딩, 제목용 나눔스퀘어라운드 글꼴
./make_video.sh                       # build/ 에 프레임·오디오를 만들고 sprout.mp4 생성

python3 sprout.py --blend sprout.blend           # Blender에서 열어볼 .blend 파일만 저장
python3 sprout.py --frames 122,175 --out test/   # 특정 프레임만 렌더
```

CPU 4코어 기준 1280×720 한 장에 약 25초(Cycles 16샘플 + 디노이즈), 180장 전체는 1시간 남짓 걸린다.
인코딩할 때 1080p로 업스케일한다.
