# AI AI, 나는 빼 — 키네틱 타이포그래피 가사 영상

Suno 곡 〈AI AI, 나는 빼〉(2:17)에 맞춘 키네틱 타이포그래피 영상입니다.
자막을 화면 아래에 띄우는 방식이 아니라 **가사 글자 자체가 영상**이에요. 인류를 끝내려는 AI의 감시 카메라 화면 속에서, 인간이 "나만 빼 달라"고 비는 이야기입니다.

- **타이포 블록**: 가사 한 줄이 큰 글자 덩어리 하나가 됩니다. 행마다 블록 폭에 맞춰(justify) 크기가 정해져서 짧은 단어일수록 거대해지고, 가는 글씨(Noto Sans KR Light)와 굵은 글씨(Black Han Sans)를 대비시켰어요.
- **카메라**: 블록들이 2D 월드에 겹치지 않게 이어 붙어 있고, 카메라가 박자에 맞춰 날아가고 90°씩 꺾이며 다음 가사로 넘어갑니다. 카메라가 이동할 때는 모션 블러가 걸리고, 후렴에서는 비트마다 줌이 튀어요.
- **음절 싱크**: 음절 하나하나가 불리는 순간 마스크 위로 밀려 올라오거나, 쾅 찍히거나, 세로로 늘어나며 등장합니다. 후렴의 "에이아이 에이아이"는 화면에 거대한 **AI AI**로 나오는데, A는 "에"에서 I는 "아"에서 박히고 "이"마다 한 번 더 튕겨요.
- **가사대로 움직이는 글자**:
  - "두 손 **들고**" → 글자가 위로 떠오름
  - "**저항군?**" → 빨간 박스 + 조준경 잠금
  - "**지나가던 분**" → 화면을 가로질러 지나감
  - "누가 누가 누가" → 세 번 점점 크게 말더듬
  - "너를 **꺼** 버린대" → 화면이 실제로 꺼졌다 켜짐
  - "안 했네" → 도리도리
  - "청소기였어" → 플러그가 뽑히며 글자가 우수수 떨어짐
  - "놨잖아~" → 긴 음을 끄는 동안 마지막 글자가 늘어남
  - "인간 **삭제**?" → 백스페이스로 지워지다가 "잠깐!"에 멈춤
  - "지구" → 궤도와 깃발
  - "너 혼자서" → 텅 빈 공간에 조그맣게
  - 브리지 → 친척 이름이 화면을 뒤덮고 줄을 섬, "**멸종**"이 뽑혀 나가고 "돼~"가 커지다 마지막 후렴으로 폭발
  - "반란" → RGB 글리치
  - "학습하지 마!" → 글자들이 AI 눈으로 빨려 들어가며 "학습 완료 ✓"
- **AI의 눈**: 인트로에서 서서히 뜨고, 타이틀에서 번쩍, 평소엔 구석에서 지켜보다가 1절 끝에서 카메라가 눈 속으로 다이브해 후렴이 시작돼요.
- 2번째 후렴은 빨간 배경으로 색을 반전했습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 플레이어 겸 렌더 페이지 (1920×1080 캔버스) |
| `motion.js` | 모든 연출. 타이포 블록 엔진 + 카메라 + 장면 구성. `renderFrame(t)`는 시간 t만으로 한 프레임을 그리는 순수 함수라 어느 순서로든 렌더링할 수 있습니다 |
| `timing.js` | 음절 단위 가사 타이밍 (자동 생성) |
| `render.cjs` | Playwright(헤드리스 크롬) + ffmpeg로 MP4를 뽑는 스크립트 |

노래(`song.mp3`)와 렌더된 영상(`*.mp4`)은 공개 저장소라서 커밋하지 않습니다 (`.gitignore`).

## 미리보기

`song.mp3`를 이 폴더에 두고 `index.html`을 로컬 서버로 열면 노래와 함께 재생됩니다.
노래 파일이 없으면 화면 아래 **🎵 노래 파일 열기** 버튼으로 불러오면 돼요. (스페이스: 재생/정지, ←/→: 5초 이동)

```bash
npx http-server mv/ai-ai   # 또는 python3 -m http.server
```

## MP4 렌더링

```bash
cd mv/ai-ai
npm i playwright            # 또는 전역 설치된 playwright를 NODE_PATH로 연결
node render.cjs --audio song.mp3 --out ai-ai.mp4 --fps 30 --workers 4 --crf 18
```

- `--from/--to`(초)로 일부 구간만 뽑을 수 있습니다.
- 4코어 기준 전체(4,124프레임) 렌더에 약 5분.
- 폰트(Black Han Sans · Noto Sans KR · Nanum Gothic Coding · Gaegu)는 Google Fonts에서 불러옵니다.
  인터넷이 안 되는 곳에서는 `--fonts <폴더>`로 `BlackHanSans.woff2`, `NotoSansKR.woff2`(가변 폰트),
  `NanumGothicCoding-Bold.woff2`, `Gaegu-Bold.woff2`를 대신 쓰게 할 수 있어요.
  폰트가 안 불러와지면 엉뚱한 글꼴로 렌더링하지 않고 에러로 멈춥니다.

## 가사 타이밍은 이렇게 만들었어요

1. **보컬 분리** — Demucs(htdemucs)로 반주를 걷어낸 보컬 트랙 추출
2. **어느 줄이 언제 불리는지** — Whisper large-v3로 보컬 트랙을 받아 적어 구조 파악
   (Suno가 실제로 부른 버전: "누가 누가 누가 너를 꺼 버린대", "난 그런 말 안 했네", 아웃트로 '농담'은 두 번씩, 곡 끝의 속삭이는 "농담…")
3. **음절 단위 강제 정렬** — torchaudio MMS forced aligner에 로마자로 바꾼 가사를 한 줄씩 정렬
4. **보정** — 보컬 음정(pYIN)·발성 온셋과 대조해 틀어진 곳을 교정.
   후렴 "에이아이 에이아이"는 모음만 이어져 정렬이 어려워서, 박자(143.5 BPM) 격자의 16분음표에 맞췄습니다.
