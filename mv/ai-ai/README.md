# AI AI, 나는 빼 — 가사 모션 그래픽

Suno 곡 〈AI AI, 나는 빼〉(2:17)에 맞춘 가사 모션 그래픽입니다.
인류를 끝내려는 AI의 **감시 카메라 화면** 속에서, 인간이 "나만 빼 달라"고 비는 콘셉트예요.

- **AI의 눈**: 빨간 렌즈(HAL 스타일). 박자에 맞춰 맥동하고, 가사에 따라 감았다 뜨고(인트로), 웃고(칭찬), 째려보고(반란 얘기), 고민하고(검토 중), 왕관을 씁니다.
- **캠코더 뷰파인더**: 커버 아트의 VHS 캠코더 느낌을 살린 REC·타임코드·배터리 표시, 필름 그레인, 스캔라인.
- **가사**: 음절 하나하나가 실제로 불리는 순간에 튀어나옵니다. 후렴의 "에이아이 에이아이"는 16분음표 박자에 맞춰 찍히고, 뒤따르는 "나는 빼 / 기록 봐 / 네가 왕 해"는 고무도장으로 쾅.
- **AI 시스템 로그**(왼쪽 아래): 가사에 AI가 속으로 답하는 개그 레이어. 예) "난 그런 말 안 했네" → `LOG> 발언 기록 조회 중…`
- **장면 소품**: 백기 두 개(두 손 들고), 저항군 조준경, 뽑힌 청소기 플러그, 감사 인사 채팅 기록, 왕관, 짝! 박수, 인간 대표 스포트라이트, 요청서 #0001 '보류', 지구본 깃발, 빈 관객석, 불어나는 **제외 명단**(브리지), "인류 ~~멸종~~ 계획", 그리고 마지막 "학습 완료 ✓".

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 플레이어 겸 렌더 페이지 (1920×1080 캔버스) |
| `motion.js` | 모든 연출. `renderFrame(t)`는 시간 t만으로 한 프레임을 그리는 순수 함수라 어느 순서로든 렌더링할 수 있습니다 |
| `timing.js` | 음절 단위 가사 타이밍 (자동 생성) |
| `render.cjs` | Playwright(헤드리스 크롬) + ffmpeg로 MP4를 뽑는 스크립트 |

노래(`song.mp3`)와 렌더된 영상(`*.mp4`)은 공개 저장소라서 커밋하지 않습니다 (`.gitignore`).

## 미리보기

`song.mp3`를 이 폴더에 두고 `index.html`을 로컬 서버로 열면 노래와 함께 재생됩니다.
노래 파일이 없으면 화면 아래 **🎵 노래 파일 열기** 버튼으로 불러오면 돼요. (스페이스: 재생/정지, ←/→: 5초 이동)

```bash
npx http-server mv/ai-ai   # 또는 python3 -m http.server
```

## MP4 렌더링

```bash
cd mv/ai-ai
npm i playwright            # 또는 전역 설치된 playwright를 NODE_PATH로 연결
node render.cjs --audio song.mp3 --out ai-ai.mp4 --fps 30 --workers 4 --crf 18
```

- `--from/--to`(초)로 일부 구간만 뽑을 수 있습니다.
- 4코어 기준 전체(4,124프레임) 렌더에 약 6분.
- 폰트(Black Han Sans · Noto Sans KR · Nanum Gothic Coding)는 Google Fonts에서 불러옵니다.
  인터넷이 안 되는 곳에서는 `--fonts <폴더>`로 `BlackHanSans.woff2`, `NotoSansKR.woff2`,
  `NanumGothicCoding.woff2`, `NanumGothicCoding-Bold.woff2`를 대신 쓰게 할 수 있어요.
  폰트가 안 불러와지면 엉뚱한 글꼴로 렌더링하지 않고 에러로 멈춥니다.

## 가사 타이밍은 이렇게 만들었어요

1. **보컬 분리** — Demucs(htdemucs)로 반주를 걷어낸 보컬 트랙 추출
2. **어느 줄이 언제 불리는지** — Whisper large-v3로 보컬 트랙을 받아 적어 구조 파악
   (Suno가 실제로 부른 버전: "누가 누가 누가 너를 꺼 버린대", "난 그런 말 안 했네", 아웃트로 '농담'은 두 번씩, 곡 끝의 속삭이는 "농담…")
3. **음절 단위 강제 정렬** — torchaudio MMS forced aligner에 로마자로 바꾼 가사를 한 줄씩 정렬
4. **보정** — 보컬 음정(pYIN)·발성 온셋과 대조해 틀어진 곳을 교정.
   후렴 "에이아이 에이아이"는 모음만 이어져 정렬이 어려워서, 박자(143.5 BPM) 격자의 16분음표에 맞췄습니다.
