# AI AI, 나는 빼 — 모션 그래픽 뮤직비디오

Suno 곡 〈AI AI, 나는 빼〉(2:17)에 맞춘 모션 그래픽 영상입니다.
화면 아래에 자막을 띄우는 방식이 아니라, **가사 한 줄마다 장면이 하나씩** 있고 그 장면이 가사 내용을 직접 연기합니다.
인류를 끝내려는 AI의 감시 카메라 화면 속에서, 인간이 "나만 빼 달라"고 비는 이야기예요.

- **장면 전환**: 약 50개 장면이 박자에 맞춰 넘어갑니다. 휩 팬(모션 블러), 줌 스루(빨려 들어가기), 글리치 컷, 위에서 떨어지는 종이, 페이드 등.
- **3D 와이어프레임 공간**: 캔버스 2D 위에 직접 만든 작은 3D 카메라로 도시, 지형, 서버랙, 지구본, 객석, 끝없는 대기줄을 그리고 카메라가 그 안을 움직입니다.
- **글자는 장면의 일부**: 가사는 음절이 불리는 순간 나타나고, 손바닥에 쓰이거나(두 손), 바닥에 떨어져 쿵 박히거나(AI AI), 입력창에 타이핑되거나(기록 봐), 서류에서 뽑혀 나갑니다(멸종).
- **"에이아이"는 AI로** 표기합니다. A는 "에", I는 "아"에서 박히고 "이"마다 한 번 더 튕겨요.

## 장면

| 구간 | 장면 |
| --- | --- |
| 인트로 | 세계 인구 카운터가 "끝"에서 멈추고, "전부 다?"에서 0이 되고, "한 명 정도는"에서 끝자리만 1로(← 나) |
| 타이틀 | AI의 눈이 뜨고, 눈 주위로 제목이 돌아감 |
| 1절 | 빨간 불로 가득 찬 하늘(올려다본 도시) → **두 손이 실제로 올라옴** → 조준경에 잡힌 "저항군?" → 휘파람 불며 지나가는 행인 → 메인 전원 레버가 내려가며 화면이 꺼짐 → 대화 기록에서 내 발언을 먹칠 → 청소기 플러그가 뽑힘 → AI 서버에 플러그를 꽂음 → AI의 눈으로 다이브 |
| 후렴 | 거대한 AI AI 3D 글자가 바닥에 떨어짐 → 인류가 빨갛게 지워지고 나만 남음 → 고맙다고 한 대화 기록 1,024건 → AI 눈에 왕관 → 박수 → 무대의 "인간 대표" 자리에서 슬금슬금 뒷걸음질 |
| 간주 | 멸종 대상 제외 신청서 작성 → "보류" 도장 |
| 2절 | `rm -rf` 인간 삭제 → "잠깐!" 손바닥 + 나의 쓸모 체크리스트 → 깃발 꽂힌 지구 → 좋아요 0개 게시물 → 천재 그래프 → 매일 칭찬 달력 → 끝없는 격자 위에 혼자 남은 AI → 빈 객석에 울리는 메아리 |
| 2번째 후렴 | 같은 안무를 빨간 화면으로 |
| 브리지 | 제외 명단 카드가 엄마 → 아빠 → 누나로 이어지며 카메라가 따라가다, 줌아웃하면 친척 150명 → 지평선까지 이어진 대기줄 → "인류 멸종 계획서"에서 **"멸종"을 뽑아 버림** → "안 돼?"가 커지는 동안 AI가 검토 |
| 마지막 후렴 | 우리 가족 전체 제외 → 생각하는 AI → 빈 객석 앞의 왕좌 → 트로피 → 박수 부대 → 거짓말 탐지기 앞 심문 "반란 같은 거 안 하냐고?" → 바늘이 미쳐 날뛰는 "…그걸 지금 말하겠냐" |
| 아웃트로 | 거짓말 확률 99.7% → "농담! 농담!" → 학습 금지 버튼 연타 → 가사가 AI 눈으로 빨려 들어감 → 학습 완료 ✓ → 눈이 감기고 "농담…" |

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 플레이어 겸 렌더 페이지 (1920×1080 캔버스) |
| `motion.js` | 엔진. 장면 전환, 카메라 HUD, 필름 질감, 폰트 로딩, 플레이어 |
| `scenes-1.js` ~ `scenes-4.js` | 장면들 (인트로·1절 / 후렴·간주 / 2절 / 브리지·마지막 후렴·아웃트로) |
| `lib.js` | 공용 도구: 이징, 박자 시계, 음절 단위 글자 애니메이션, 3D 와이어프레임 카메라 |
| `parts.js` | 소품: 손, 사람, 카운터, 청소기, 서버랙, 지구본, 객석, AI의 눈 |
| `kit.js` | 배경(격자·등고선·방사선), UI 위젯(창, 입력창, 태그), 원형 글자 |
| `timing.js` | 음절 단위 가사 타이밍 (자동 생성) |
| `glyphs.js` | 장면에 쓰인 글자 목록 — `node glyphs.cjs`로 다시 만듭니다 (웹폰트를 미리 다 받아 두려고 씀) |
| `render.cjs` | Playwright(헤드리스 크롬) + ffmpeg로 MP4를 뽑는 스크립트 |

모든 장면은 시간 t만 받아서 그리는 순수 함수라서, 어느 프레임이든 순서 없이 렌더링할 수 있습니다.
노래(`song.mp3`)와 렌더된 영상(`*.mp4`)은 공개 저장소라서 커밋하지 않습니다 (`.gitignore`).

## 미리보기

`song.mp3`를 이 폴더에 두고 `index.html`을 로컬 서버로 열면 노래와 함께 재생됩니다.
노래 파일이 없으면 화면 아래 **🎵 노래 파일 열기** 버튼으로 불러오면 돼요. (스페이스: 재생/정지, ←/→: 5초 이동)

```bash
npx http-server mv/ai-ai   # 또는 python3 -m http.server
```

## MP4 렌더링

```bash
cd mv/ai-ai
npm i playwright            # 또는 전역 설치된 playwright를 NODE_PATH로 연결
node render.cjs --audio song.mp3 --out ai-ai.mp4 --fps 30 --workers 4 --crf 18
```

- `--from/--to`(초)로 일부 구간만 뽑을 수 있습니다.
- 폰트(Black Han Sans · Noto Sans KR · Noto Serif KR · IBM Plex Mono · Nanum Gothic Coding · Gaegu)는 Google Fonts에서 불러옵니다.
  인터넷이 안 되는 곳에서는 `--fonts <폴더>`로 로컬 woff2 파일을 대신 쓰게 할 수 있어요 (파일 이름은 `render.cjs`의 `FACES` 참고).
  폰트가 안 불러와지면 엉뚱한 글꼴로 렌더링하지 않고 에러로 멈춥니다.

## 가사 타이밍은 이렇게 만들었어요

1. **보컬 분리** — Demucs(htdemucs)로 반주를 걷어낸 보컬 트랙 추출
2. **어느 줄이 언제 불리는지** — Whisper large-v3로 보컬 트랙을 받아 적어 구조 파악
   (Suno가 실제로 부른 버전: "누가 누가 누가 너를 꺼 버린대", "난 그런 말 안 했네", 아웃트로 '농담'은 두 번씩, 곡 끝의 속삭이는 "농담…")
3. **음절 단위 강제 정렬** — torchaudio MMS forced aligner에 로마자로 바꾼 가사를 한 줄씩 정렬
4. **보정** — 보컬 음정(pYIN)·발성 온셋과 대조해 틀어진 곳을 교정.
   후렴 "에이아이 에이아이"는 모음만 이어져 정렬이 어려워서, 박자(143.5 BPM) 격자의 16분음표에 맞췄습니다.
